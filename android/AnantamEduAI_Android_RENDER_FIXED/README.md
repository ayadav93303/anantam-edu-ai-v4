# Anantam Edu AI Android — Stable V9 Client

Open this folder in Android Studio and build the APK.

The app connects to the Render backend at:

`https://anantam-edu-ai-v4.onrender.com`

Features:
- AI chat with image-question support
- detailed chapter notes
- All Chapters / Full Syllabus notes, chapter by chapter
- organized exam papers with answer keys
- practice generator with selectable class, subject, chapter, question count, difficulty and question type
- answers/explanations for practice questions
- voice input
- image upload/camera with removable preview
- LaTeX/dollar-sign cleanup for generated educational content
- backend warm-up and automatic retry handling

If your Render URL changes, edit `app/src/main/assets/app.js` and change `API_BASE` near the top.
